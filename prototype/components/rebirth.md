# Rebirth

## Core Idea

Run restart after Life is spent.

## Trigger

- Life reaches 0.
- Swordsman Guild unlock shown.
- Game Over screen asks if life was well spent.

## Verbs

- Die
- Judge
- Reborn
- Restart

## Rules

On Reborn:
- Life resets to 100.
- Combat HP resets full.
- Aging sprite resets to Born.
- Inventory resets to starter loadout.
- Current run XP reset/persist TBD.
- Swordsman Guild unlock persistence TBD.

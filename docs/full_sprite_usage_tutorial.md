# Using Full LPC Spritesheets In Godot

This project uses LPC-format character spritesheets generated by `tools/lpc-sprite-gen/`.
Do not crop the sheet down to one row or one frame for runtime animation.

## The Asset Format

Generated LPC sheets are full animation atlases:

- Sheet width: `832px`
- Cell size: `64x64`
- Columns: `13`
- Rows: `21`
- Example asset: `res://assets/player.png`

The current broken implementation uses `player_anim.png`, a `332x61` crop of the top row.
That crop only contains back-facing frames and does not preserve the LPC grid.

## LPC Row Layout

The generator stacks animations in this order:

| Animation | Rows | Columns Used |
| --- | ---: | ---: |
| `spellcast` | `0..3` | `0..6` |
| `thrust` | `4..7` | `0..7` |
| `walk` | `8..11` | `0..8` |
| `slash` | `12..15` | `0..5` |
| `shoot` | `16..19` | `0..12` |
| `hurt` | `20` | `0..5` |

For the four-direction animations, rows are ordered:

| Direction | Row Offset |
| --- | ---: |
| `up` / back-facing | `0` |
| `left` | `1` |
| `down` / front-facing | `2` |
| `right` | `3` |

For example, walk rows are:

| Direction | Row |
| --- | ---: |
| `walk_up` | `8` |
| `walk_left` | `9` |
| `walk_down` | `10` |
| `walk_right` | `11` |

## Option A: Use Sprite2D Directly

This is the simplest built-in Godot setup.

1. Select the player `Sprite2D`.
2. Set `Texture` to `res://assets/player.png`.
3. Set `Hframes` to `13`.
4. Set `Vframes` to `21`.
5. Drive `frame_coords` from code.

Example:

```gdscript
extends Sprite2D

const COLUMNS := 13

const ROWS := {
	"idle_up": 0,
	"idle_left": 1,
	"idle_down": 2,
	"idle_right": 3,
	"walk_up": 8,
	"walk_left": 9,
	"walk_down": 10,
	"walk_right": 11,
}

var direction := "down"
var animation_name := "idle"
var frame_index := 0
var frame_timer := 0.0


func _ready() -> void:
	hframes = COLUMNS
	vframes = 21
	_apply_frame()


func _process(delta: float) -> void:
	if animation_name == "walk":
		frame_timer += delta
		if frame_timer >= 0.12:
			frame_timer = 0.0
			frame_index = (frame_index + 1) % 9
			_apply_frame()
	else:
		frame_index = 0
		_apply_frame()


func play_walk(new_direction: String) -> void:
	animation_name = "walk"
	direction = new_direction


func play_idle(new_direction: String) -> void:
	animation_name = "idle"
	direction = new_direction
	frame_index = 0
	_apply_frame()


func _apply_frame() -> void:
	var row_key := "%s_%s" % [animation_name, direction]
	var row: int = ROWS.get(row_key, ROWS["idle_down"])
	frame_coords = Vector2i(frame_index, row)
```

Use `frame_coords = Vector2i(column, row)` instead of manually cropping PNGs.

## Option B: Use AnimatedSprite2D

Use this if you want named animations in the editor.

1. Create a `SpriteFrames` resource.
2. Add animations like `walk_down`, `walk_up`, `idle_down`, etc.
3. For each animation, add frames from `res://assets/player.png`.
4. Each frame must be a `64x64` region.
5. Keep the original atlas intact.

This is more manual unless you write an importer script.

## About LPCAnimatedSprite2D

`LPCAnimatedSprite2D` is a spritesheet-generation workflow, not the runtime animation node this project should depend on.
Use it, or this repo's `tools/lpc-sprite-gen/`, to produce the full LPC PNG.

At runtime, keep the generated sheet intact and animate it with Godot nodes:

- `Sprite2D` with `hframes = 13`, `vframes = 21`, and `frame_coords`
- or `AnimatedSprite2D` / `SpriteFrames` built from `64x64` atlas regions

Do not replace the full sheet with generated one-row or one-frame crops.

## Direction From Movement

For 2D movement, choose the dominant axis:

```gdscript
func direction_from_vector(delta: Vector2) -> String:
	if abs(delta.x) > abs(delta.y):
		return "right" if delta.x > 0.0 else "left"
	return "down" if delta.y > 0.0 else "up"
```

Then call:

```gdscript
var dir := direction_from_vector(destination - global_position)
play_walk(dir)
```

When the player stops, keep the same direction:

```gdscript
play_idle(direction)
```

## What Not To Do

Do not:

- Crop `player.png` to `player_anim.png`.
- Use `hframes = 4` for a full LPC sheet.
- Treat columns `0..3` as directions.
- Use `83x61` frame slices.
- Commit scene references to cropped one-row textures.

The correct LPC cell size is `64x64`, and directions are rows, not columns.
